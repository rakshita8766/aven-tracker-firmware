Command 	Description

AT+QMTCFG	Configure MQTT parameters: Sets version (3.1/3.1.1), keepalive, session type,      and SSL/TLS settings.
AT+QMTOPEN	Open Network: Establishes a TCP connection to the MQTT broker's host and port.
AT+QMTCONN	Connect to Broker: Sends the MQTT CONNECT packet with ClientID, username, and password.
AT+QMTSUB	Subscribe: Subscribes to one or more topics with a specific QoS level.
AT+QMTPUBEX	Publish Message: Sends a message to a specific topic. You will receive a > prompt to enter your data.
AT+QMTUNS	Unsubscribe: Unsubscribes from specific topics.
AT+QMTDISC	Disconnect: Disconnects the client from the MQTT broker.
AT+QMTCLOSE	Close Network: Closes the underlying network connection.

AT+QFUPL="UFS:cacert.pem",<file_size>,100                                     (QUECTEL FILE UPLOAD)
QFUPL → stores certificate
QSSLCFG → uses certificate

1] AT+QSSLCFG="<parameter>",<sslctxid>,<value> // 

<parameter> → What you are configuring
<sslctxid> → SSL context ID (usually 1)
<value> → Setting value

2] Security Level
AT+QSSLCFG="seclevel",1,1
Value	Meaning
0	No verification
1	Verify server (most used)
2	Mutual authentication

3] SSL Version
AT+QSSLCFG="sslversion",1,4
Value	TLS Version
0	SSL 3.0
1	TLS 1.0
2	TLS 1.1
3	TLS 1.2
4	TLS 1.2 (recommended)

4] SNI (Server Name Indication)
AT+QSSLCFG="sni",1,1

✔️ Required for cloud brokers

5] Ignore Local Time
AT+QSSLCFG="ignorelocaltime",1,1

✔️ Avoids certificate time errors
